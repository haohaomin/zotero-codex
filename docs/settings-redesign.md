# 设置页设计优化

日期：2026-10-02。当前为开发分支中的界面优化，基于 0.8.1，未发布稳定版本或替换日常安装。

沿用 Zotero 原生 XUL 容器和 XHTML 控件，无新增前端框架或外部设计依赖。界面采用中性色、圆角分组、细分隔线和系统字体，跟随宿主浅色/深色主题；无装饰动画。主要识别点是顶部的运行状态标签和三列服务概览。

- 按钮按「准备组件 → 连接 Codex」排列：未准备时突出准备，失败时显示重试，就绪后显示重新检查并突出连接；准备或连接进行中锁定两项操作，定时刷新不会提前解锁。
- 连接按钮、组件准备进度、本地桥接/API/Better Notes 状态集中展示。
- 运行环境选项、版本和访问记录默认折叠；状态标签区分准备中、组件就绪、Codex 已配置和异常，不将配置成功表述为客户端在线。
- 阅读捕获选项改为整行可点击、说明在下、勾选框在右的布局。
- 其他客户端的配置复制独立展示，路径和开发者模式收在高级设置内；保留全部关键用途说明。
- 刷新反馈保留在按钮右侧，允许换行；按钮与输入框统一圆角，保留键盘 focus-visible 提示。
- 关闭自动准备后的空闲状态不再显示“正在检查 Node.js”。

修改文件为 `addon/content/preferences.xhtml`、`preferences.css`、`preferences.js`，宿主回归使用 `scripts/settings-host-smoke.js`。

验证：53 项现有测试通过；在隔离 Zotero 10.0.4 中通过 [35 项设置页检查](settings-redesign-result.json)。检查覆盖正常、准备中、失败、已配置状态，读取开关、上下文清除、开发者配置导出、诊断及 360px 容器无横向溢出。检查了浅色和深色真实宿主截图。XHTML 解析、JavaScript 语法和开发预览 XPI 的 ZIP 完整性检查通过。未做 Windows/Linux 图形宿主验收或屏幕阅读器实测。

预览包：`dist/zotero-codex-settings-preview.xpi`，保留基础版本 0.8.1，仅用于开发预览，不能视为正式 Release。远程访问尚未实现，因此设置中没有添加不可用的远程开关。
